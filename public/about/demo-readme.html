What This Demo Shows

The current Fi We Boledo app is a great first step into a digital lottery experience. The demo I built shows what a next version of that app could look and feel like — with stronger security, a friendlier user experience, and the ability to buy tickets directly with a Belizean debit or credit card through Belize Bank, alongside the existing DigiWallet option.

Current Fi We Boledo App

  • Customers can only pay using DigiWallet
  • No fingerprint or face login

Boledo v2 Demo

How to Install and Open the Demo

The demo is designed to work entirely on your phone — no internet servers, accounts to set up, or technical configuration needed. Five simple steps:

Open the demo folder
Click the link in my cover letter or CV (or scan the QR code on my résumé). It opens a Google Drive folder containing the app.
Download the file named "app-release.apk"
On an Android phone or tablet, tap the file name and choose "Download" — it is about 100 MB and will save to your Downloads folder.
Allow the install (one-time only)
When you tap the downloaded file, Android may ask if it can install apps from this source. Tap "Settings" → enable "Allow from this source" → then tap back. This is normal for any app not yet on the Play Store, and is safe.
Tap "Install"
Android will install the app in a few seconds. Tap "Open" when it finishes, or find "Boledo" in your app drawer like any other app.
Sign in with the demo account below
Use the credentials in the next section to sign in. The app works fully offline — you can navigate the entire experience without an internet connection.

Suggested Tour (5 Minutes)

If you have a few minutes, here are the screens that show the biggest differences from the current app:

  • Sign In screen — note the password show/hide button, the "Use Fingerprint" option, and the cleaner overall layout.
  • Home screen — your wallet balance is now visible at the top, the next draw has a live countdown, and each game has its own colour and feel.
  • Buy a Boledo number — easier number entry, a clear explanation of "Pieces", and a confirmation step before the wager is final.
  • Payment Information screen — your bank account number is hidden except for the last four digits, and you can add a Belize Bank debit/credit card alongside DigiWallet.
  • My Tickets screen — friendly illustrations and clear actions when you have not yet purchased a ticket.
  • Winning Numbers — historical results, a draw archive, and visual emphasis on the latest winning numbers.
  • Profile and Settings — proper name capitalisation, clearer reasons when a field is locked, and a smoother account-update flow.

An Honest Note

This is a demonstration, not a finished replacement product. A few things — like sending real text-message verification codes, or actually charging a Belize Bank card — are placeholders, because those require live agreements and credentials that only BGLL holds. Everything you see, however, reflects the same design system, security thinking, and engineering quality I use to ship my live M3 Marketplace platform.

The goal is simple: to show direction and capability, not to claim a finished product. If you would like a deeper walkthrough — including the source code, the admin web panel, or live screen-sharing of the same flows — I would be glad to do that at interview.
